# Mission: 教團隊使用 Matt Pocock 的 agent skills

## Why
我想先真正理解 Matt Pocock 官方技能庫，之後能向團隊解釋各技能的用途、選用時機與組合方式，並帶領同事用實際工程情境練習，而不是只照著指令操作。

## Success looks like
- 能根據團隊的真實開發情境選出合適技能，說明選擇理由與順序。
- 能拆解一份 `SKILL.md`，指出觸發條件、執行步驟、參考資料與完成標準。
- 能向團隊示範如何評估一個技能是否設計得好，並引導案例討論。

## Constraints
- 從「只聽過 agent skills 概念」開始，以繁體中文循序漸進教學。
- 以 Matt Pocock 的官方 repository 和文件為主要來源。
- 每課短而聚焦，使用實際案例與回饋檢驗理解。

## Out of scope
- 目前沒有指定排除的相鄰主題。
