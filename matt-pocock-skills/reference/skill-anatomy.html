如何讀一份 SKILL.md

先分辨「入口資訊」與「執行指令」。再問：誰會呼叫它？何時呼叫？執行後留下什麼？

---
name: example-skill
description: 這個技能做什麼，以及適用情境
disable-model-invocation: true  # 如果只讓使用者主動呼叫
---

# 正文
何時使用、要讀哪些資料、依序做什麼、完成如何判定。

這是教學示意，並非官方檔案原文。不同技能的欄位與正文組織會有所不同。

位置要回答的問題閱讀提示
name這個技能叫什麼？與目錄及呼叫名稱對照。
description它做什麼？什麼情境會想到它？模型可呼叫的技能尤其需要清楚的觸發條件。
disable-model-invocation只有人主動呼叫，還是 agent 也可依情境採用？true 表示手動呼叫；若要模型也能呼叫，依官方文件省略此欄位，並寫明 description 的觸發情境。
正文實際怎麼做？何時算完成？找步驟、決策分支、引用的附加文件及完成標準。

官方對兩種呼叫方式的說明見 Skill mechanics。設計正文時，可參考 writing-for-agents 對脈絡指標、資訊層級與可檢查完成標準的說明。
